# BB Model Usage Widget

Виджет для [BB](https://getbb.app), который показывает в заголовке потока:

- через какой маршрут идут запросы — Умка, личный OpenAI/Anthropic или другой шлюз;
- модель текущего потока;
- остаток личных лимитов, который сообщает BB;
- расходуются ли эти личные лимиты текущим маршрутом.

Кнопка с диаграммой появляется в верхней панели потока. Данные обновляются при
открытии pop-up и затем раз в минуту.

## Поддерживаемые маршруты

- **Codex:** читает `model_provider` и `base_url` из `~/.codex/config.toml`.
- **Claude Code:** читает только `ANTHROPIC_BASE_URL` и модель из
  `~/.claude/settings.json` либо окружения процесса.
- **Умка:** распознаётся по домену `umka.up-advert.ru`.

Плагин не использует, не сохраняет и не передаёт API-ключи. Он использует штатный API BB для
личных лимитов. Умка не публикует числовой остаток общего корпоративного
лимита, поэтому виджет честно показывает его как активный, но без выдуманного
процента.

## Установка

Из GitHub:

```bash
bb plugin install https://github.com/sevavsegdakotov/bb-plugin-model-usage-widget
```

Из локальной папки:

```bash
npm install
bb plugin install .
```

После изменения исходников:

```bash
npm run typecheck
bb plugin build
bb plugin reload model-usage-widget
```

## Требования

- BB 0.43 или новее;
- Plugin SDK 0.4.104 или новее;
- текущая проверка профиля Claude ориентирована на формат настроек Claude Code.

## Архитектура

- `app.tsx` — кнопка и pop-up в `experimental_threadHeaderAction`;
- `server.ts` — объединяет данные маршрута, модели и лимитов;
- `host.ts` — локально определяет маршрут без чтения секретов;
- `contracts.ts` — проверяемые RPC-контракты между частями плагина.

## Проверка

```bash
npm run typecheck
bb plugin build
```

После установки статус обоих маршрутов можно проверить через RPC плагина или
просто открыть pop-up в потоке Codex и Claude Code.
